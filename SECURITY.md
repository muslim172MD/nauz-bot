# Security and privacy

## Секреты

- Никогда не коммитьте `TELEGRAM_TOKEN`, `ANTHROPIC_API_KEY` и другие ключи.
- Секреты передаются только через переменные окружения/секрет-хранилище платформы.
- При подозрении на утечку ключ немедленно ротируется.

## Данные пациентов

Этот проект не предназначен для обработки идентифицирующих данных пациентов.

Не вводите и не сохраняйте:
- ФИО пациента;
- СНИЛС, полис ОМС, паспортные данные;
- номер истории болезни;
- телефон, адрес, дату рождения;
- иные данные, позволяющие идентифицировать пациента.

Приложение содержит базовый защитный фильтр явных маркеров таких данных, но он не является полноценным DLP-решением и не гарантирует обнаружение всех чувствительных данных.

## Хранение диалогов

`SAVE_DIALOGS=false` — безопасное значение по умолчанию.

Если сохранение включается, нужно заранее определить:
- законное основание и цель хранения;
- срок хранения;
- круг лиц с доступом;
- шифрование и резервное копирование;
- процедуру удаления.

## Сообщение об уязвимости

Не публикуйте токены, персональные данные или подробности эксплуатации уязвимости в публичном issue. Используйте приватный канал владельца проекта.
